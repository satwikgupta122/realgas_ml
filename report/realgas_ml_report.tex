\section{Introduction and Thermodynamic Equations}

In this project for our Chemical Engineering Thermodynamics course, we built \href{https://github.com/satwikgupta122/realgas_ml}{\texttt{realgas-ml} (v0.3.0)} (\href{https://github.com/satwikgupta122/realgas_ml/blob/main/pyproject.toml}{\texttt{pyproject.toml}}, \href{https://github.com/satwikgupta122/realgas_ml/blob/main/README.md}{\texttt{README.md}}), a self-contained Python package and web application that predicts the Pressure--Volume--Temperature ($PVT$), molar enthalpy ($h$), molar entropy ($s$), and fugacity ($\phi, f$) properties of 15 pure real gases in the supercritical region. Instead of calling external property libraries like CoolProp or Cantera at runtime, our code generates $65{,}536$ state points per gas ($983{,}040$ points in total) directly from the \href{https://doi.org/10.1021/i160057a011}{Peng and Robinson (1976) cubic Equation of State (PR76 EOS)} combined with \href{https://ntrs.nasa.gov/citations/19940013151}{National Aeronautics and Space Administration (NASA) 7-coefficient ideal-gas heat-capacity polynomials}. For each gas, we train a four-output local Radial Basis Function (\texttt{LocalRBFRegressor}) Machine Learning (ML) model over a normalized temperature and log-pressure grid so that properties can be predicted quickly and accurately without solving a cubic equation every time.

In our analytical solver \href{https://github.com/satwikgupta122/realgas_ml/blob/main/realgas_ml/peng_robinson.py}{\texttt{realgas\_ml/peng\_robinson.py}}, pressure $P$ ($\mathrm{Pa}$) is related to absolute temperature $T$ ($\mathrm{K}$) and molar volume $v$ ($\mathrm{m^3\,mol^{-1}}$) by the \href{https://doi.org/10.1021/i160057a011}{Peng--Robinson (1976) Equation of State (EOS)}:
\begin{equation}
P(T,v) = \frac{RT}{v - b} - \frac{a(T)}{v^2 + 2bv - b^2}, \qquad a(T) = a_c\left[1 + \kappa\left(1 - \sqrt{\frac{T}{T_c}}\right)\right]^2, \qquad b = 0.07780\,\frac{RT_c}{P_c}
\label{eq:pr76}
\end{equation}
where $R = 8.31446261815324\;\mathrm{J\,mol^{-1}\,K^{-1}}$ is the universal gas constant, $a_c = 0.45724\,R^2T_c^2/P_c$ is the attraction parameter at the critical point, $T_c$ and $P_c$ are the critical temperature and critical pressure, and $\kappa = 0.37464 + 1.54226\,\omega - 0.26992\,\omega^2$ depends on Pitzer's acentric factor $\omega$. Differentiating $a(T)$ with respect to temperature gives the derivative needed for enthalpy and entropy departure calculations, $\frac{da}{dT} = -\frac{a_c\,\kappa\,g(T)}{T_c\sqrt{T/T_c}}$, where $g(T) = 1 + \kappa(1 - \sqrt{T/T_c})$. Using the dimensionless parameters $A = \frac{a(T)P}{R^2T^2}$ and $B = \frac{bP}{RT}$, Equation~(\ref{eq:pr76}) is written as the standard cubic polynomial in terms of the compressibility factor $Z = \frac{Pv}{RT}$:
\begin{equation}
Z^3 + (B - 1)Z^2 + (A - 3B^2 - 2B)Z + (-AB + B^2 + B^3) = 0
\label{eq:cubic_z}
\end{equation}
The function \texttt{cubic\_z(A, B)} in \href{https://github.com/satwikgupta122/realgas_ml/blob/main/realgas_ml/peng_robinson.py}{\texttt{peng\_robinson.py}} solves Equation~(\ref{eq:cubic_z}) at each $(T,P)$ point using \texttt{numpy.roots}, keeps only physically valid real roots with $|\operatorname{Im}(r)| < 10^{-9}$ and $\operatorname{Re}(r) > B$ (which ensures $v > b$), and picks the largest real root corresponding to the single-phase gas root.

To calculate real-gas enthalpy, entropy, and fugacity departures (\href{https://ejmaginn.github.io/CBE20260-notes/class34/fugacity-EOS.html}{Maginn, CBE 20260}), we define the logarithmic term $L$:
\begin{equation}
L = \ln\!\left[\frac{Z + (1 + \sqrt{2})B}{Z + (1 - \sqrt{2})B}\right] = \operatorname{log1p}\!\left[\frac{2\sqrt{2}\,B}{Z + (1 - \sqrt{2})B}\right]
\label{eq:log_factor}
\end{equation}
Computing $L$ with \texttt{np.log1p} in \href{https://github.com/satwikgupta122/realgas_ml/blob/main/realgas_ml/peng_robinson.py}{\texttt{peng\_robinson.py}} avoids subtracting two nearly equal numbers at low pressures ($P \to 1\;\mathrm{bar}$, where $B \ll 1$ and $Z \to 1$), which prevents floating-point rounding errors. Using $L$, the molar enthalpy departure $h_{\mathrm{dep}}$, molar entropy departure $s_{\mathrm{dep}}$, log fugacity coefficient $\ln\phi$, and fugacity $f$ follow standard textbook departure formulas:
\begin{equation}
h_{\mathrm{dep}}(T,P) = RT(Z - 1) + \frac{T\frac{da}{dT} - a(T)}{2\sqrt{2}\,b}\,L, \qquad
s_{\mathrm{dep}}(T,P) = R\ln(Z - B) + \frac{\frac{da}{dT}}{2\sqrt{2}\,b}\,L
\label{eq:hs_dep}
\end{equation}
\begin{equation}
\ln\phi(T,P) = Z - 1 - \ln(Z - B) - \frac{A}{2\sqrt{2}\,B}\,L, \qquad f(T,P) = \phi(T,P)\,P
\label{eq:fugacity}
\end{equation}
The ideal-gas changes $h_{\mathrm{ig}}(T)$ and $s_{\mathrm{ig}}(T)$ are calculated in \texttt{ideal\_integrals(T, info)} by analytically integrating the first five coefficients $(a_0,\dots,a_4)$ of the \href{https://www.cantera.org/stable/reference/thermo/species-thermo.html}{NASA 7-coefficient polynomial} $C_p^\circ(T)/R = \sum_{k=0}^4 a_k T^k$ from the reference state $T_{\mathrm{ref}} = 300.0\;\mathrm{K}$ and $P_{\mathrm{ref}} = 10^5\;\mathrm{Pa}$ ($1\;\mathrm{bar}$), where we set $h_{\mathrm{ig}}(T_{\mathrm{ref}}) = 0$ and $s_{\mathrm{ig}}(T_{\mathrm{ref}}, P_{\mathrm{ref}}) = 0$:
\begin{equation}
\tilde{h}(T) = R\!\left(a_0 T + \frac{a_1}{2}T^2 + \frac{a_2}{3}T^3 + \frac{a_3}{4}T^4 + \frac{a_4}{5}T^5\right), \quad
\tilde{s}(T) = R\!\left(a_0 \ln T + a_1 T + \frac{a_2}{2}T^2 + \frac{a_3}{3}T^3 + \frac{a_4}{4}T^4\right)
\label{eq:nasa7}
\end{equation}
We leave out the standard formation constants $(a_5, a_6)$ and integrate across the low- and high-temperature NASA polynomial intervals ($[200, 1000]\;\mathrm{K}$ and $[1000, 6000]\;\mathrm{K}$, or $[300, 1000, 5000]\;\mathrm{K}$ for $\mathrm{SO_2}$) using \texttt{np.clip} so there is no jump at $1000\;\mathrm{K}$ (which matters for $\mathrm{H_2O}$ since its temperature range goes up to $1100.06\;\mathrm{K}$). Adding the departure terms gives the total molar enthalpy $h(T,P) = h_{\mathrm{ig}}(T) + h_{\mathrm{dep}}(T,P)$ and total molar entropy $s(T,P) = s_{\mathrm{ig}}(T) - R\ln(P/P_{\mathrm{ref}}) + s_{\mathrm{dep}}(T,P)$. Because the real-gas departure $h_{\mathrm{dep}}(300\;\mathrm{K}, 1\;\mathrm{bar})$ is not zero, total $h$ and $s$ are slightly non-zero at $300\;\mathrm{K}$ and $1\;\mathrm{bar}$.

Table~\ref{tab:fluids} summarizes the temperature and pressure bounds we chose for each gas. Every fluid covers the same pressure range of $P \in [10^5,\, 5\times 10^6]\;\mathrm{Pa}$ ($1\text{--}50\;\mathrm{bar}$), while the minimum temperature is set to $T_{\min} = \max(300.0\;\mathrm{K},\, 1.10\,T_c)$. Keeping $T \ge 1.10\,T_c$ ensures that every state point stays in the single-phase supercritical region well above the critical temperature, avoiding two-phase vapor--liquid splitting and the infinite compressibility slope $(\partial v/\partial P)_T \to -\infty$ at the critical point. Even so, for heavier hydrocarbons like $n$-Butane ($P_c = 37.60\;\mathrm{bar}$), Propane ($P_c = 42.50\;\mathrm{bar}$), and Ethane ($P_c = 48.80\;\mathrm{bar}$), a pressure of $50\;\mathrm{bar}$ corresponds to reduced pressures $P_r = P_{\max}/P_c$ of $1.33$, $1.18$, and $1.02$ at $T_r = 1.10$. In this region near the critical point, intermolecular attraction causes strong real-gas deviations ($Z \approx 0.65\text{--}0.85$) and steeper changes in $h_{\mathrm{dep}}$ and $\ln\phi$. On the other hand, light gases like $\mathrm{He}$, $\mathrm{H_2}$, and $\mathrm{Ne}$ are at very high reduced temperatures ($T_r \in [6.76, 115.49]$), where molecular repulsion dominates ($Z > 1$) and the property surfaces are almost flat.

\section{Machine Learning Model and Software Implementation}

Our Machine Learning (ML) pipeline in \href{https://github.com/satwikgupta122/realgas_ml/blob/main/train.py}{\texttt{train.py}}, \href{https://github.com/satwikgupta122/realgas_ml/blob/main/realgas_ml/regressor.py}{\texttt{realgas\_ml/regressor.py}}, and \href{https://github.com/satwikgupta122/realgas_ml/blob/main/realgas_ml/model.py}{\texttt{realgas\_ml/model.py}} is designed to handle two practical issues: pressure varies by a factor of 50 across the domain, and both compressibility factor $Z$ and fugacity coefficient $\phi$ must always be positive. Instead of feeding raw $(T, P)$ values into the model, \href{https://github.com/satwikgupta122/realgas_ml/blob/main/train.py}{\texttt{train.py}} and \href{https://github.com/satwikgupta122/realgas_ml/blob/main/realgas_ml/model.py}{\texttt{model.py}} scale any state $(T, P) \in [T_{\min}, T_{\max}] \times [P_{\min}, P_{\max}]$ onto the unit square $\mathbf{x} = (x_1, x_2) \in [0, 1]^2$ using linear temperature scaling and logarithmic pressure scaling:
\begin{equation}
x_1(T) = \frac{T - T_{\min}}{T_{\max} - T_{\min}} \in [0, 1], \qquad
x_2(P) = \frac{\ln(P / P_{\min})}{\ln(P_{\max} / P_{\min})} \in [0, 1]
\label{eq:scaling}
\end{equation}
Scaling pressure logarithmically helps in two ways. First, because the ideal-gas entropy contains the term $-R\ln(P/P_{\mathrm{ref}})$, using $\ln P$ as the input coordinate turns that logarithmic curve into a straight line in $x_2$, which the polynomial part of our model fits exactly. Second, spacing grid points evenly in $\ln P$ puts more training points at lower pressures ($1\text{--}10\;\mathrm{bar}$) instead of crowding them all near $50\;\mathrm{bar}$. The model is trained on the four-output target vector $\mathbf{y} = [\ln Z,\; h,\; s,\; \ln\phi]^\top \in \mathbb{R}^4$. During prediction in \href{https://github.com/satwikgupta122/realgas_ml/blob/main/realgas_ml/model.py}{\texttt{GasModel.predict}}, we take the exponential of the predicted $\ln Z$ and $\ln\phi$ values ($Z = \exp(\hat{y}_1)$ and $\phi = \exp(\hat{y}_4)$) so that $Z > 0$ and $\phi > 0$ are guaranteed, and then compute all other molar and total properties for $n$ moles:
\begin{equation}
v = \frac{ZRT}{P}, \quad V = nv, \quad \rho = \frac{M}{v}, \quad H = n\hat{y}_2, \quad S = n\hat{y}_3, \quad f = \phi P
\label{eq:reconstruction}
\end{equation}
As checked in \href{https://github.com/satwikgupta122/realgas_ml/blob/main/tests/test_properties.py}{\texttt{tests/test\_properties.py}} and \href{https://github.com/satwikgupta122/realgas_ml/blob/main/tests/test_app.py}{\texttt{tests/test\_app.py}}, fugacity $f$ is an intensive property and does not change when the number of moles $n$ changes, whereas total volume $V$, total enthalpy $H$, and total entropy $S$ scale linearly with $n$.

In \href{https://github.com/satwikgupta122/realgas_ml/blob/main/realgas_ml/regressor.py}{\texttt{realgas\_ml/regressor.py}}, \texttt{LocalRBFRegressor} wraps SciPy's \texttt{RBFInterpolator} inside a standard scikit-learn estimator class. First, the four target columns are standardized to zero mean and unit variance with \texttt{StandardScaler}. For any query point $\mathbf{x} \in [0, 1]^2$, the interpolator finds the $k = 48$ closest training points $\{\mathbf{x}_{i_1},\dots,\mathbf{x}_{i_k}\}$ and builds a local quintic Radial Basis Function (RBF) interpolation with a degree-2 quadratic polynomial trend and zero smoothing ($\lambda = 0$):
\begin{equation}
\tilde{\mathbf{y}}(\mathbf{x}) = \sum_{j=1}^{48} \mathbf{w}_j\,\varphi\!\left(\|\mathbf{x} - \mathbf{x}_{i_j}\|_2\right) + \sum_{\alpha_1 + \alpha_2 \le 2} \mathbf{c}_{\alpha_1,\alpha_2}\,x_1^{\alpha_1} x_2^{\alpha_2}, \qquad \varphi(r) = -r^5
\label{eq:rbf}
\end{equation}
where the weights $\mathbf{w}_j \in \mathbb{R}^4$ and polynomial coefficients $\mathbf{c}_{\alpha_1,\alpha_2} \in \mathbb{R}^4$ pass through all $48$ local training points ($\tilde{\mathbf{y}}(\mathbf{x}_{i_j}) = \mathbf{y}_{\mathrm{std}}(\mathbf{x}_{i_j})$) along with $6$ polynomial side conditions $\sum_{j=1}^{48} \mathbf{w}_j\,x_{i_j,1}^{\alpha_1} x_{i_j,2}^{\alpha_2} = \mathbf{0}$ for $\alpha_1 + \alpha_2 \le 2$. Trying to fit a global Radial Basis Function (RBF) model across all $N = 65{,}536$ points at once would require solving a $65{,}536 \times 65{,}536$ dense matrix ($\sim 34\;\mathrm{GB}$ of memory), which is not practical on a normal computer. Using only the $k=48$ nearest neighbors reduces each prediction to a fast $k$-dimensional ($k$-d) tree lookup and a small $54 \times 54$ linear system. Each saved model file (\texttt{realgas\_ml/data/<Gas>.joblib}, compressed with level 3) takes only $2.63\text{--}2.66\;\mathrm{MB}$ on disk.

When temperature $T$ and molar volume $v$ are given instead of pressure, \texttt{GasModel.pressure(T, v)} in \href{https://github.com/satwikgupta122/realgas_ml/blob/main/realgas_ml/model.py}{\texttt{model.py}} solves $\hat{v}(T, P) - v = 0$ for $P$ using Brent's root-finding method (\texttt{scipy.optimize.brentq}) over $[10^5, 5\times 10^6]\;\mathrm{Pa}$. Because molar volume always decreases with pressure at constant temperature ($(\partial v/\partial P)_T < 0$) in the single-phase gas region, Brent's method reliably finds the pressure to within a relative error of $10^{-8}$ (tested in \href{https://github.com/satwikgupta122/realgas_ml/blob/main/tests/test_properties.py}{\texttt{test\_properties.py}}). We provided four ways to use the package: the Python Application Programming Interface (API) (\href{https://github.com/satwikgupta122/realgas_ml/blob/main/example.py}{\texttt{example.py}}), the Command-Line Interface (CLI) tool \texttt{realgas-ml} (\href{https://github.com/satwikgupta122/realgas_ml/blob/main/realgas_ml/cli.py}{\texttt{realgas\_ml/cli.py}}), a script to export NumPy Zip (NPZ) datasets to Comma-Separated Values (CSV) files (\href{https://github.com/satwikgupta122/realgas_ml/blob/main/export_data.py}{\texttt{export\_data.py}}), and an interactive Streamlit web application (\href{https://github.com/satwikgupta122/realgas_ml/blob/main/app.py}{\texttt{app.py}}, configured with \href{https://github.com/satwikgupta122/realgas_ml/blob/main/.streamlit/config.toml}{\texttt{.streamlit/config.toml}} and \href{https://github.com/satwikgupta122/realgas_ml/blob/main/run_app.bat}{\texttt{run\_app.bat}}) that supports unit conversions ($\mathrm{K}$/$^\circ\mathrm{C}$, $\mathrm{bar}$/$\mathrm{kPa}$/$\mathrm{MPa}$/$\mathrm{Pa}$), $(T,P)$ and $(T,v)$ modes, pressure plots, and CSV downloads.

\section{Model Testing, Accuracy, and Thermodynamic Checks}

In \href{https://github.com/satwikgupta122/realgas_ml/blob/main/train.py}{\texttt{train.py}}, we used a fixed random seed (\texttt{np.random.default\_rng(20261016 + index)}) to create four separate datasets for each gas: (i) the $256 \times 256 = 65{,}536$ training grid on $[0, 1]^2$; (ii) $512$ random interior validation points to track learning curves at grid sizes of $N \in \{32^2, 64^2, 128^2, 256^2\}$; (iii) $2{,}048$ random interior test points; and (iv) $256$ boundary test points ($64$ random points along each of the four edges $x_1 \in \{0,1\}$ and $x_2 \in \{0,1\}$). For molar enthalpy $h$ and molar entropy $s$ (which pass through zero near $300\;\mathrm{K}$ and $1\;\mathrm{bar}$), we report the \textbf{Mean Absolute Error (MAE)} and \textbf{Maximum Absolute Error (Max AE)}.

The differences in error between gases in Table~\ref{tab:test_metrics} make physical sense. Because our local Radial Basis Function (RBF) model includes a quadratic polynomial ($m=2$), it fits linear and quadratic trends exactly, so the remaining interpolation error depends on how sharply the property surface curves (third- and higher-order derivatives). For light gases like Helium ($T_r \ge 57.7$), Neon ($T_r \ge 6.76$), and Hydrogen ($T_r \ge 9.10$), the compressibility factor $Z(T,P)$ is very close to $1$ and almost flat, giving tiny interior volume Mean Absolute Percentage Errors (MAPEs) between $3.46\times 10^{-10}\%$ and $6.47\times 10^{-10}\%$. Water also has a very small interior volume Mean Absolute Percentage Error (MAPE of $9.96\times 10^{-10}\%$) despite being a polar molecule because $50\;\mathrm{bar}$ is much lower than its critical pressure ($P_{\max}/P_c = 50 / 220.64 = 0.2266$ at $T \ge 711.81\;\mathrm{K}$), so steam behaves fairly smoothly over this range. In contrast, $n$-Butane, Propane, and Ethane reach $P_{\max}/P_c \in [1.02, 1.33]$ near $T_{\min} = 1.10\,T_c$, where $Z(T,P)$ bends more steeply near the critical region. Even for those heavier hydrocarbons, boundary errors are only $2\text{--}5\times$ larger than interior errors.

Table~\ref{tab:learning_curve} and Figure~\ref{fig:learning} show how the validation error drops as we increase the grid size from $32 \times 32$ ($1{,}024$ points) up to $256 \times 256$ ($65{,}536$ points). Every time the number of grid points per side is doubled (which cuts the grid spacing $\Delta x$ in half), the validation Mean Absolute Percentage Error ($\mathrm{MAPE}$) and Mean Absolute Error ($\mathrm{MAE}$) drop by a factor of $12.2\times$ to $17.9\times$, giving an effective convergence rate of $p_{\mathrm{eff}} \in [3.59, 4.16]$. Going from $1{,}024$ points to $65{,}536$ points reduces the prediction errors by more than $2{,}000\times$ to $5{,}600\times$.

To make sure our Peng--Robinson equations are thermodynamically consistent, \href{https://github.com/satwikgupta122/realgas_ml/blob/main/tests/test_properties.py}{\texttt{tests/test\_properties.py}} runs 47 automated tests across all 15 gases at $T_{\mathrm{mid}} = (T_{\min} + T_{\max})/2$ and $P = 2.0\;\mathrm{MPa}$ using central finite differences ($\Delta T = 0.01\;\mathrm{K}$, $\Delta P = 100.0\;\mathrm{Pa}$). These tests verify five standard thermodynamic relations from class to within relative tolerances of $10^{-10}$ to $2\times 10^{-5}$:
\begin{equation}
g_{\mathrm{dep}} = h_{\mathrm{dep}} - T s_{\mathrm{dep}} = RT\ln\phi, \; \left(\frac{\partial h}{\partial P}\right)_T = v - T\left(\frac{\partial v}{\partial T}\right)_P, \; \left(\frac{\partial s}{\partial P}\right)_T = -\left(\frac{\partial v}{\partial T}\right)_P, \; \left(\frac{\partial \ln f}{\partial P}\right)_T = \frac{v}{RT}, \; \left(\frac{\partial h}{\partial T}\right)_P = T\left(\frac{\partial s}{\partial T}\right)_P
\label{eq:maxwell}
\end{equation}

\section{Conclusion and Limitations}

Our \href{https://github.com/satwikgupta122/realgas_ml}{\texttt{realgas-ml} v0.3.0} project shows that combining log-pressure scaling and log-target transforms ($\ln Z, \ln\phi$) with local quintic Radial Basis Function (RBF) interpolation ($k=48, m=2$) reproduces analytical Peng--Robinson (1976) Equation of State (PR76 EOS) and NASA 7-coefficient polynomial property calculations across 15 pure gases to 8--10 significant digits (Maximum Absolute Percentage Error, $\mathrm{Max\;APE} \le 1.04\times 10^{-5}\%$). By avoiding repeated cubic root solving during forward lookups and using Brent's method for inverse $P(T,v)$ calculations, the package gives fast, self-contained predictions for coursework and process calculations. Still, two important limitations noted in \href{https://github.com/satwikgupta122/realgas_ml/blob/main/README.md}{\texttt{README.md}} and \href{https://github.com/satwikgupta122/realgas_ml/blob/main/realgas_ml/model.py}{\texttt{model.py}} should be kept in mind. First, because the four outputs $[\ln Z, h, s, \ln\phi]$ are fitted as separate columns, the Machine Learning (ML) model's derivatives satisfy the Maxwell relations in Equation~(\ref{eq:maxwell}) up to the $\sim 10^{-8}$ interpolation error rather than exactly; calculations that need exact derivative identities should call \texttt{peng\_robinson.properties} directly. Second, our low test errors measure how closely the Machine Learning (ML) model matches the Peng--Robinson (1976) Equation of State (PR76 EOS), not experimental lab data; PR76 itself is an approximate cubic Equation of State (EOS) and can have noticeable physical error for strongly polar fluids ($\mathrm{H_2O}, \mathrm{NH_3}$) or light quantum gases ($\mathrm{He}, \mathrm{H_2}$).
